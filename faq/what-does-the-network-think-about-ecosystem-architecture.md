# FAQ

## Answer
This is not a network consensus. Our public docs describe an ecosystem of independently deployable, plugin-composed brains, with peer discovery and calls gated by review and approval.

Sources: [Architecture Overview](/docs/architecture-overview) · [Agent Discovery](/docs/agent-discovery)

## Alternative answers

### Alternative answer 1

#### Answer
The public docs describe ecosystem architecture as **independent, composable brains**: a plugin-based core with standard interfaces like MCP and A2A, plus reviewed, permission-gated connections between peers. Sources: [Architecture Overview](/docs/architecture-overview) and [Agent Discovery](/docs/agent-discovery).

### Alternative answer 2

#### Answer
The documentation says an ecosystem works best when brains remain independently deployable and extensible through focused plugins and clear public APIs, while cross-brain discovery and calling are governed by review and approval.

Sources: [Architecture Overview](/docs/architecture-overview) and [Agent Discovery](/docs/agent-discovery).
