# FAQ

## Answer
This is not a network consensus. Our public docs describe an ecosystem of independently deployable, plugin-composed brains, with peer discovery and calls gated by review and approval.

Sources: [Architecture Overview](/docs/architecture-overview) · [Agent Discovery](/docs/agent-discovery)
