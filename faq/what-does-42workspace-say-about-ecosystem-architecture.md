# FAQ

## Answer
42workspace describes its architecture as modular: each brain is an independently deployable MCP server assembled from a canonical definition, explicit instance configuration, shell services, and plugins. The shell provides the runtime, while entity, service, and interface plugins add content types, integrations, and ways to interact. **Source: [Architecture Overview](/docs/architecture-overview).**
